## G2. Платформа (Paddle)

**Вопрос 1:** размеры платформы.

**Ответ всех версий:** нормальная ширина = 120 пикселей, увеличенная = 180, высота = 15.

**Вопрос 2:** скорость движения.

**Ответ всех версий:** 8 пикселей/кадр.

**Вопрос 3:** длительность бонуса увеличения.

| Версия | Длительность |
|--------|---------------|
| v1 | ❌ бонуса нет |
| v2 | 15 секунд (900 кадров) |
| v3–v4 | **30 секунд** (1800 кадров) *(увеличено для баланса)* |

## G3. Мяч (Ball)

**Вопрос 1:** радиус мяча.

| Версия | Радиус |
|--------|--------|
| v1 | 8 пикселей |
| v2–v4 | **7 пикселей** *(уменьшен для более точной коллизии)* |

**Вопрос 2:** начальное положение.

| Версия | Положение |
|--------|------------|
| v1 | Центр экрана (400, 300) |
| v2–v4 | Над платформой (SCREEN_WIDTH//2, SCREEN_HEIGHT-100) |

**Вопрос 3:** начальная скорость.

| Версия | Скорость |
|--------|----------|
| v1 | speed_x = 5, speed_y = -5 (фиксированные) |
| v2–v4 | speed_x = random.choice([-4, 4]), speed_y = -5 *(вариативность для разнообразия)* |

**Вопрос 4:** изменение скорости при ударе о платформу.

**Ответ всех версий c v1:**  
speed_x = (hit_pos - 0.5) × коэффициент.

| Версия | Коэффициент |
|--------|-------------|
| v1 | 10 |
| v2–v4 | **8** *(снижен для лучшей управляемости)* |

**Вопрос 5:** поддержка нескольких мячей.

| Версия | Поддержка |
|--------|-----------|
| v1 | ❌ только один мяч |
| v2–v4 | ✅ массив balls, поддержка мульти-мяча |

## G4. Кирпичи (Bricks)

**Вопрос 1:** размеры.

| Версия | Ширина | Высота |
|--------|--------|--------|
| v1 | 75 | 20 |
| v2–v4 | **70** | **22** *(уточнено для лучшей компоновки)* |

**Вопрос 2:** прочность (strength).

| Версия | Система |
|--------|---------|
| v1 | strength = 3 (верхний ряд), 2 (средние ряды), 1 (нижние ряды) |
| v2–v4 | **Зависит от раскладки уровня** (см. G6) |

**Вопрос 3:** визуальное отображение прочности.

| Версия | Отображение |
|--------|-------------|
| v1 | Звездочки '★' × strength |
| v2–v4 | **Кружки '●'** × strength *(более аркадный стиль)* |

**Вопрос 4:** очки за разрушение.

**Ответ всех версий:** 10 очков за кирпич (независимо от прочности).

## G5. Бонусы (Bonuses)

**Вопрос 1:** типы бонусов.

| Тип | Эффект | Символ | Цвет |
|-----|--------|--------|------|
| EXTRA_LIFE | +1 жизнь | "+1" | RED |
| MULTI_BALL | +3 мяча | "3x" | GREEN |
| BIG_PADDLE | Увеличение платформы | "⇔" | BLUE |

**Вопрос 2:** логика выпадения.

| Версия | Логика |
|--------|--------|
| v2 | Вероятностная: 15% (+жизнь), 25% (3x), 60% (платформа) |
| v3–v4 | **Детерминированная:** `brick_index % 3` — равномерное распределение, привязанное к порядку разрушения |

**Вопрос 3:** количество бонусов на уровень.

**Ответ всех версий c v2:** `max(1, total_bricks // 5)` — примерно каждый 5-й кирпич.

**Вопрос 4:** скорость падения.

**Ответ всех версий c v2:** 3 пикселя/кадр.

**Вопрос 5:** возможность применения бонусов несколько раз.

**Ответ:** все бонусы стеклятся (кроме BIG_PADDLE — перезаписывает таймер).

## G6. Уровни (Levels)

**Вопрос 1:** количество уровней.

| Версия | Количество |
|--------|------------|
| v1 | 1 (фиксированный) |
| v2–v4 | **10** |

**Вопрос 2:** источник данных об уровнях.

| Версия | Источник |
|--------|----------|
| v1 | Жёстко закодированы в `create_bricks()` |
| v2–v4 | Файл `levels.json` |

**Вопрос 3:** раскладки (bricks_layout).

**Доступные типы:**

| Раскладка | Описание | Особенность |
|-----------|----------|-------------|
| classic | Классическая сетка | Все строки полные |
| pyramid | Пирамида | Центрированные треугольные блоки |
| zigzag | Зигзаг | Каждый 3-й кирпич усиленный (strength=2) |
| double | Двойной слой | Верхние 2 ряда — strength=3 |
| rainbow | Радуга | Цвета по диагонали |
| checkerboard | Шахматная доска | Только чёрные клетки (через один) |
| castle | Крепость | Края и низ — strength=3 |
| spiral | Спираль | Чётные слои — strength=2 |
| dense | Плотный слой | Прочность = 1 + ряд//2 |
| boss | Финальный босс | Все кирпичи strength=3, цвет PURPLE |

**Вопрос 4:** какие параметры настраиваются для уровня.

**Ответ:** id, rows (количество рядов), cols (количество колонок), bricks_layout, description.

## G7. Меню и навигация

**Вопрос 1:** пункты главного меню.

**Ответ всех версий c v2:** "Начать игру", "Выбрать уровень", "Выход".

**Вопрос 2:** выбор уровня.

| Версия | Функциональность |
|--------|------------------|
| v1 | ❌ нет |
| v2 | Заблокированные уровни — серым, только доступные можно выбрать |
| v3–v4 | + отображение рекорда на кнопке уровня |

**Вопрос 3:** начало игры.

**Ответ:** "Начать игру" запускает последний доступный (максимальный разблокированный) уровень.

## G8. Прогресс и сохранение

**Вопрос 1:** что сохраняется.

| Версия | Сохраняемые данные |
|--------|---------------------|
| v1 | ❌ ничего |
| v2 | unlocked_levels (разблокированные уровни) |
| v3–v4 | unlocked_levels + **high_scores** (рекорды по уровням) |

**Вопрос 2:** формат файла.

**Ответ:** `progress.json`:

```json
{
    "unlocked_levels": [1, 2, 3, ...],
    "high_scores": {
        "1": 100,
        "2": 250,
        ...
    }
}
```

**Вопрос 3:** когда сохраняется рекорд.

**Ответ v3–v4:** после завершения уровня, если текущий счёт выше сохранённого.

**Вопрос 4:** отображение прогресса в меню.

| Версия | Отображение |
|--------|-------------|
| v2 | Только количество доступных уровней |
| v3–v4 | Количество уровней + **общая сумма рекордов** |

## G9. Жизни и Game Over

**Вопрос 1:** стартовое количество жизней.

**Ответ всех версий:** 3.

**Вопрос 2:** что происходит при потере мяча.

| Версия | Поведение |
|--------|-----------|
| v1 | Мяч сбрасывается в центр, платформа сбрасывается |
| v2–v4 | Удаление мяча. Если мячей не осталось: lives--. Если lives>0 — новый мяч над платформой, платформа сбрасывается |

**Вопрос 3:** поддержка нескольких мячей.

| Версия | При потере одного мяча |
|--------|------------------------|
| v1 | ❌ (только 1 мяч) |
| v2–v4 | ✅ удаляется только упавший, остальные продолжают игру |

**Вопрос 1:** какие состояния существуют.

| Состояние | v1 | v2 | v3–v4 |
|-----------|----|----|-------|
| PLAYING | ✅ | ✅ | ✅ |
| PAUSED | ✅ | ✅ | ✅ |
| GAME_OVER | ✅ | ✅ | ✅ |
| LEVEL_COMPLETE | ❌ (сразу победа) | ✅ | ✅ |

**Вопрос 2:** переход между уровнями.

| Версия | Поведение |
|--------|-----------|
| v1 | После уничтожения всех кирпичей — GAME OVER с надписью "YOU WIN!" |
| v2–v4 | LEVEL_COMPLETE → ожидание ENTER → загрузка следующего уровня. После уровня 10 — GAME OVER (победа) |
