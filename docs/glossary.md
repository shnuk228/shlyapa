Глоссарий игровых сущностей — Arkanoid Quiz (v4)

**Версия:** 4.0  
**Дата:** 2026-05-27  
**Основание:** Анализ `v4.py`

| Сущность | Атрибут | Тип данных | Описание |
|---|---|---|---|
| **Шарик (Ball)** | Радиус | Целое (7 px) | Размер шарика |
| | Скорость X | Целое | -5..5 (изменяется при ударе о платформу) |
| | Скорость Y | Целое | -5..5 |
| | Активен | Булево | True пока не упал за платформу |
| **Платформа (Paddle)** | Нормальная ширина | 120 px | |
| | Большая ширина | 180 px | |
| | Таймер большого размера | Целое (кадры) | 1800 кадров = 30 сек при FPS=60 |
| **Кирпич (Brick)** | Прочность | 1..3 | 3-прочные оранжевые, 2-прочные жёлтые, 1-прочные зелёные |
| | Цвет | (R,G,B) | Меняется при уменьшении прочности |
| **Падающий бонус (Bonus)** | Тип | `EXTRA_LIFE`, `MULTI_BALL`, `BIG_PADDLE` | Выпадает из кирпича при разрушении |
| | Скорость Y | 3 px/кадр | Падает вниз |
| **Накопленный бонус (Stored Bonus)** | Тип | `BIG_PADDLE`, `MULTI_BALL`, `BOTTOM_SHIELD` | Хранится в `stored_bonuses` (макс. 3) |
| | Активация | Клавиши 1,2,3 | Применяет эффект, удаляет из запаса |
| **Защита дна (Bottom Shield)** | Таймер | 30 * FPS кадров | (~30 сек). Шарики отскакивают от нижней границы |
| **Вопрос квиза (Quiz Question)** | Текст | Строка | Загружается из `questions.json` |
| | Варианты | Список[4] | A, B, C, D |
| | Правильный ответ | Индекс 0..3 | |
| **Состояние игры** | `running`, `paused`, `game_over`, `level_complete`, `_quiz` active | Перечисление / словарь | Поддерживает вложенный квиз во время игры |
| **Обучение (Tutorial)** | `tutorial_step` | 0,1,2 | 0=движение, 1=поймать бонус, 2=завершено |
| | `tutorial_bonus_caught` | Булево | Запомнить, что обучение пройдено |
