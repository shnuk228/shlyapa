# Глоссарий игровых сущностей — ARKANOID

**Версия:** 1.0  
**Дата:** 13-05-2026  

| Сущность | Атрибут | Тип данных | Описание |
|---|---|---|---|
| **Платформа (Paddle)** | Ширина | Целое число = 120 (нормальная) / 180 (увеличенная) | Ширина платформы в пикселях |
| | Высота | Целое число = 15 | Высота платформы |
| | Позиция X | Целое число | Левая граница платформы |
| | Таймер увеличения | Целое число (кадры) | Оставшееся время увеличенного состояния |
| **Мяч (Ball)** | Радиус | Целое число = 7 | Радиус мяча в пикселях |
| | Скорость X | Вещественное число | Горизонтальная скорость (пикселей/кадр) |
| | Скорость Y | Вещественное число | Вертикальная скорость |
| | Активен | Логический | Не улетел ли за нижнюю границу |
| **Кирпич (Brick)** | Ширина | Целое число = 70 | Ширина кирпича |
| | Высота | Целое число = 22 | Высота кирпича |
| | Прочность | Целое число (1–3) | 1 = обычный, 2 = усиленный, 3 = супер-прочный |
| | Цвет | Цвет | Зависит от прочности и раскладки |
| | Особый | Логический | Для будущих расширений |
| **Бонус (Bonus)** | Тип | Перечисление | `EXTRA_LIFE`, `MULTI_BALL`, `BIG_PADDLE` |
| | Скорость Y | Целое число = 3 | Скорость падения |
| | Активен | Логический | Не достиг ли дна |
| **Уровень (Level)** | ID | Целое число (1–10) | Номер уровня |
| | Строки (rows) | Целое число | Количество рядов кирпичей |
| | Столбцы (cols) | Целое число | Количество колонок |
| | Раскладка | Строка | `classic`, `pyramid`, `zigzag`, `double`, `rainbow`, `checkerboard`, `castle`, `spiral`, `dense`, `boss` |
| **Прогресс** | Разблокированные уровни | Список целых чисел | Какие уровни доступны |
| | Рекорды уровней | Словарь {строка: число} | Лучший счёт для каждого уровня |
| **Состояние игры** | Текущее состояние | Перечисление | `PLAYING`, `PAUSED`, `GAME_OVER`, `LEVEL_COMPLETE` |
| **Счёт** | Текущий счёт | Целое число | Сумма очков за уровень |
| **Жизни** | Количество | Целое число (0–...) | Стартовое = 3 |
